# Terraform2Sheet 仕様書 (2025-12-15版)

## 概要

Terraform planの出力（JSON形式）をHTMLテーブルに変換するツール。
リソース設定システムにより、柔軟なファイル配置と表示方法をカスタマイズ可能。

## アーキテクチャ

### 3ステージパイプライン

```
plan.json + schema.json
  ↓
[1] data_extraction (lib/data_extraction.py)
  ↓ extracted_data.json (OriginValue形式)
[2] formatting_data (lib/formatting_data.py)
  ↓ formatted_data.json (ViewValue形式)
[3] html_view (lib/html_view.py)
  ↓ HTML files (階層的ディレクトリ構造)
```

### データ構造の変換

#### Stage 1: data_extraction
- 入力: `plan.json` + `schema.json`
- 出力: `extracted_data.json` (OriginValue形式)
- 処理内容:
  - リソースの抽出
  - スキーマ情報の統合
  - OriginValueオブジェクトの生成（value, reference, description, required）

#### Stage 2: formatting_data
- 入力: `extracted_data.json`
- 出力: `formatted_data.json` (ViewValue形式)
- 処理内容:
  - 参照解決: `aws_iam_policy.example` → `(ref) example-policy-name`
  - 特殊処理: `aws_iam_role_policy_attachment` → IAM Roleに統合
  - ViewValue変換: OriginValue → ViewValue (value, description, required)
  - table_type決定: individual/list

#### Stage 3: html_view
- 入力: `formatted_data.json`
- 出力: HTMLファイル群
- 処理内容:
  - リソース設定に基づくファイル振り分け
  - 展開可能パラメータの処理
  - HTMLテーブル生成
  - 階層的ディレクトリ構造の作成

## リソース設定システム (lib/resource_config.py)

### 設定項目

各リソースタイプに対して以下を定義:

```python
{
  "resource_types": ["aws_iam_role"],        # 対象リソースタイプ（複数指定可）
  "file_path": "aws/iam/role.html",          # 出力先HTMLファイル
  "priority": 1,                             # 同一ファイル内での優先順位（低い方が先）
  "sort_by": "name",                         # ソートキー（"name", "tags.Name", "bucket"など）
  "special_parameters": [                    # 特殊表示パラメータ
    {
      "name": "assume_role_policy",          # パラメータ名
      "display": "collapsible",              # 表示方法（collapsible = 折りたたみ）
      "is_json": True                        # JSON整形の有無
    }
  ]
}
```

## 展開可能パラメータ機能

### 概要

大きなJSON値（ポリシードキュメント、user_dataなど）を折りたたんで表示し、クリックで展開可能にする。

### 実装方法

- HTML5の `<details>` / `<summary>` 要素を使用（JavaScriptなし）
- JSON値は自動的に整形（indent=2）
- 最大高さ400pxでスクロール可能

### 設定例

```python
"special_parameters": [
  {
    "name": "assume_role_policy",
    "display": "collapsible",
    "is_json": True
  }
]
```

### HTML出力例

```html
<details>
  <summary>assume_role_policyを表示</summary>
  <div class="collapsible-content">{
  "Statement": [
    {
      "Action": "sts:AssumeRole",
      "Effect": "Allow",
      "Principal": {
        "Service": "lambda.amazonaws.com"
      }
    }
  ],
  "Version": "2012-10-17"
}</div>
</details>
```

### 現在設定されている展開可能パラメータ

- `aws_iam_role`: assume_role_policy, inline_policy
- `aws_iam_policy`: policy
- `aws_iam_role_policy`: policy
- `aws_iam_user_policy`: policy
- `aws_iam_group_policy`: policy
- `aws_s3_bucket_policy`: policy
- `aws_lambda_function`: environment
- `aws_instance`: user_data

## リソースのソート

### ソート順序

同一HTMLファイル内のリソースは以下の順序でソート:

1. **priority** (昇順) - リソースタイプの優先度
2. **sort_key value** (昇順) - 設定されたソートキーの値
3. **resource_name** (昇順) - リソース名

### ソートキーの種類

- `name`: nameパラメータの値
- `bucket`: bucketパラメータの値
- `function_name`: function_nameパラメータの値
- `tags.Name`: tagsのNameフィールドの値（ネスト対応）
- `identifier`: identifierパラメータの値

### ソート処理の実装

```python
# lib/html_view.py の _group_resources_by_file() 内
resources.sort(key=lambda r: (
  resource_config.get_priority(r['resource_type']),
  _get_sort_value(r, resource_config.get_sort_key(r['resource_type'])),
  r['resource_name']
))
```

## 参照解決

### 基本ルール

Terraform参照（`aws_iam_policy.example`）を実際のリソース名に解決:

```
aws_iam_policy.example → (ref) example-policy-name
```

### 識別子属性マッピング

リソースタイプごとに識別子として使用する属性を定義:

```python
RESOURCE_IDENTIFIER_ATTRIBUTES = {
  'aws_iam_role': 'name',
  'aws_iam_policy': 'name',
  'aws_s3_bucket': 'bucket',
  'aws_lambda_function': 'function_name',
  'aws_vpc': 'tags.Name',
  'aws_subnet': 'tags.Name',
  'aws_instance': 'tags.Name',
  # デフォルト: 'name'
}
```

### ネスト属性の対応

`tags.Name` のようなネスト属性にも対応:

```python
def _get_resource_identifier(resource, resource_type):
  identifier_attr = RESOURCE_IDENTIFIER_ATTRIBUTES.get(resource_type, 'name')
  if '.' in identifier_attr:
    parts = identifier_attr.split('.')
    value = resource.get('values', {})
    for part in parts:
      value = value.get(part)
    return value.value if hasattr(value, 'value') else value
```

## 特殊処理

### aws_iam_role_policy_attachment

IAMロールへのポリシーアタッチメントを、IAMロールリソースに統合:

```python
# 処理前
aws_iam_role.lambda_role
  name: "lambda-role"

aws_iam_role_policy_attachment.lambda_logs
  role: aws_iam_role.lambda_role
  policy_arn: "arn:aws:iam::aws:policy/CloudWatchLogsFullAccess"

# 処理後
aws_iam_role.lambda_role
  name: "lambda-role"
  attached_policies: [
    {
      value: "(ref) cloudwatch-logs-policy",
      description: "",
      required: false
    }
  ]

# aws_iam_role_policy_attachment は出力されない
```

## HTMLテーブル形式

### Individual型（詳細表示）

1リソースを詳細に表示。ネスト構造と配列を適切に表現:

```
┌─────────────────────────────────┬────────┬──────┬──────┐
│ パラメータ                      │ 値     │ 必須 │ 説明 │
├────────┬────┬──────┬────────────┼────────┼──────┼──────┤
│ name   │ -  │      │            │ role-1 │ Yes  │      │
├────────┼────┼──────┼────────────┼────────┼──────┼──────┤
│ ingress│ -  │ 1    │ from_port  │ 443    │ Yes  │      │
│        │    │      ├────────────┼────────┼──────┼──────┤
│        │    │      │ to_port    │ 443    │ Yes  │      │
│        │    ├──────┼────────────┼────────┼──────┼──────┤
│        │    │ 2    │ from_port  │ 80     │ Yes  │      │
│        │    │      ├────────────┼────────┼──────┼──────┤
│        │    │      │ to_port    │ 80     │ Yes  │      │
└────────┴────┴──────┴────────────┴────────┴──────┴──────┘
```

特徴:
- rowspanで同一値のセルを結合
- 配列要素は1始まりのインデックス表示
- 単純属性は全カラムをcolspanで結合

### List型（一覧表示）

複数リソースを1行ずつ表示（現在は未実装、個別型で代用）:

```
┌──────────────┬────────┬──────┬──────┐
│ リソース名   │ name   │ tags │ ...  │
├──────────────┼────────┼──────┼──────┤
│ resource1    │ value1 │ ...  │ ...  │
├──────────────┼────────┼──────┼──────┤
│ resource2    │ value2 │ ...  │ ...  │
└──────────────┴────────┴──────┴──────┘
```

## ディレクトリ構造

### 生成されるHTML構造

```
output_dir/
├── index.html                    # 目次ページ
└── {provider}/
    └── {service}/
        └── {resource}.html       # リソース詳細ページ
```

### 戻りリンクの実装

ネストの深さに応じて相対パスを自動計算:

```python
# lib/html_view.py の _generate_file_html() 内
depth = file_path.count('/')
back_link = '../' * depth + 'index.html'
```

例:
- `aws/iam/role.html` → `../../index.html`
- `aws/s3/bucket.html` → `../../index.html`
- `unknown/other.html` → `../index.html`

## 使用方法

### 基本的な実行フロー

```bash
# 1. Terraform planの出力
terraform plan -out=plan.tfplan
terraform show -json plan.tfplan > plan.json

# 2. スキーマの取得
terraform providers schema -json > schema.json

# 3. データ抽出
python -m lib.data_extraction plan.json schema.json -o extracted.json

# 4. データ整形
python -m lib.formatting_data extracted.json -o formatted.json

# 5. HTML生成
python -m lib.html_view formatted.json -o html_output -t "My Infrastructure"
```

### 出力例

```
html_output/
├── index.html
└── aws/
    ├── iam/
    │   ├── role.html
    │   └── policy.html
    └── s3/
        └── bucket.html
```

## カスタマイズ方法

### 新しいリソースタイプの追加

`lib/resource_config.py` の `RESOURCE_CONFIGS` に追加:

```python
{
  "resource_types": ["aws_dynamodb_table"],
  "file_path": "aws/dynamodb/table.html",
  "priority": 1,
  "sort_by": "name",
  "special_parameters": [
    {
      "name": "attribute",
      "display": "collapsible",
      "is_json": True
    }
  ]
}
```

### 展開可能パラメータの追加

既存の設定に `special_parameters` を追加:

```python
"special_parameters": [
  {
    "name": "my_large_parameter",
    "display": "collapsible",
    "is_json": False  # JSON整形が不要な場合
  }
]
```

### 識別子属性のカスタマイズ

`lib/formatting_data.py` の `RESOURCE_IDENTIFIER_ATTRIBUTES` に追加:

```python
RESOURCE_IDENTIFIER_ATTRIBUTES = {
  'aws_dynamodb_table': 'name',
  'aws_elasticsearch_domain': 'domain_name',
  # ...
}
```

## 制限事項

### 現在の制限

1. **List型テーブル未実装**: 全て個別型で表示
2. **プロバイダー**: AWS以外は未テスト
3. **モジュール参照**: `module.xxx` 形式の参照は解決されない
4. **複雑なネスト**: 3階層以上のネストは表示が複雑になる可能性

### 今後の拡張予定

1. List型テーブルの実装
2. カスタムdescriptionの対応
3. 差分表示（create/update/delete）
4. フィルタリング・検索機能
5. エクスポート機能（CSV、Excel）
