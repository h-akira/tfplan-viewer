# Schema Description Writer

Add Japanese `"description"` to attributes in `schema/d*/*.json` files.

## Key Rules

- `"description"` と `"description_kind"` は別物。`description_kind` は変更しない
- `computed: true` かつ `optional` がないもの（読み取り専用）はスキップ
- 英語のdescriptionは日本語で上書きする
- 既存の日本語descriptionはユーザー指示がない限り上書きしない
- descriptionは簡潔な日本語（1〜2文）で書く

JSON形式の詳細は [references/schema_format.md](references/schema_format.md) を参照。

## Workflow

### 1. 対象ファイル特定

ユーザーがdXXXXやファイルを指定した場合はそれに従う。指定がなければ:

```bash
python3 <skill_dir>/scripts/list_missing.py <schema_dir>
```

`list_missing.py` は日本語descriptionが未記入の属性を一覧表示する。
`--json` オプションでJSON出力、`--dXXXX d0000` で特定バージョンのみスキャン可能。

### 2. description生成・書き込み

対象ファイル数に応じて処理方法を選択する。

**ファイルが少数（1〜2個）の場合**: 直接Editツールで編集。

**ファイルが多数（3個以上）の場合**: カスタムサブエージェント `schema-description` が利用可能であれば、それを使って並列処理する。利用できない場合はTaskツールで並列処理するか、順次Editツールで編集する。同時実行数は最大5に制限する（MCP APIの負荷軽減のため）。

### 3. 確認

編集後、`list_missing.py` を再実行して残りがないか確認。
